# QuickNotes

QuickNotes is a small browser-based note app for capturing personal reminders, work tasks, and study ideas. Notes stay in the browser, so the list is ready when you return to the page.

## Features

- Add notes with Personal, Work, or Study categories.
- See each note's category and creation date.
- Delete individual notes.
- Search note text without regard to capitalization.
- Get a helpful error for blank notes or notes longer than 200 characters.
- Keep notes between visits with browser `localStorage`.
- Use a responsive layout that adapts to small screens.

## Run locally

No installation or build step is needed. Clone or download this repository, then open `index.html` in a modern web browser. You can also serve the folder with any static file server.

## What I learned

- How to select elements and update the DOM with JavaScript.
- How to create safe note cards with `createElement` and `textContent`.
- How to handle form events, validation, deletion, and live search.
- How JSON and `localStorage` can preserve an array of objects across page refreshes.
